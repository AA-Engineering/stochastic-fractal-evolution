# Thirteen-role SFE Research Implementation Panel

These are **research workstreams**, not 13 independently instantiated AI chatbots. No independent-agent consensus is claimed.

| Role | Workstream | Required deliverable |
|---|---|---|
| 01 | Literature reviewer | Prior-art map with verifiable sources |
| 02 | Linear algebra | Determinant/rank/eigenvalue checks |
| 03 | Stochastic processes | Known-answer probability benchmarks |
| 04 | Numerical analysis | Convergence and error tests |
| 05 | Geodynamic modeler | Governing equations and rheology |
| 06 | Plate reconstruction | Historical boundary/rotation datasets |
| 07 | Geomorphology | Erosion/drainage physics |
| 08 | Data provenance | Data leakage and licensing checks |
| 09 | Scientific software | Reproducible reference engine |
| 10 | Uncertainty quantification | Ensemble calibration and sensitivity |
| 11 | Visualization | Mathematics + hypothetical/reference maps |
| 12 | Adversarial auditor | Counterexamples and falsification |
| 13 | Open-science editor | Citation, DOI, releases, disclosures |

## Review gates

No claimed geophysical result may be called validated until roles 02–04 and 05–12 have independently auditable evidence. No claimed consensus without separate recorded assessments. Random seeds choose exploratory trajectories, never scientific truth.

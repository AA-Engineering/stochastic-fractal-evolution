# Public Dissemination and Release Checklist

- [x] Public GitHub repository and open MIT license
- [x] Citation metadata (CITATION.cff)
- [x] Zenodo deposit metadata (.zenodo.json)
- [x] Public research landing page
- [x] Initial reproducible known-answer control
- [ ] Independent code review and tests on multiple environments
- [ ] Verify source references and correct unsupported statements
- [ ] Add a clear release tag (e.g. v0.1.0) after review
- [ ] Connect repository to Zenodo using repository owner's Zenodo account
- [ ] Archive the tagged GitHub release and verify the issued DOI
- [ ] Link DOI back into CITATION.cff and README
- [ ] Publish empirical plate-tectonic hindcast outputs with provenance
- [ ] Prepare independent-review manuscript
- [ ] Consider Figshare/Hugging Face datasets and demos
- [ ] Consider arXiv only when manuscript and submission rules are satisfied

**Important:** Creating .zenodo.json does not deposit or publish anything on Zenodo. GitHub is the only confirmed publication destination at this stage.

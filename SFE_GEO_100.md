# SFE-GEO-100 — North American Plate at +100 Ma

## Current default conceptual scenario

This record freezes the current visual/model concept for the SFE long-horizon North American Plate experiment.

### Default process

```text
present-day topography
 -> multiscale/fractal seed
 -> stochastic tectonic evolution
 -> geophysical constraint filtering
 -> repeated admissible trajectories
 -> geological attractor analysis
 -> ensemble-derived future topography
```

### Interpretation

The current +100 Ma illustration is a **conceptual SFE-GEO scenario and visual reference**. It must not be represented as the numerical mean of an executed 10,000-run or larger geodynamic ensemble. The labeled geological features are hypotheses to be tested by the future executable SFE-GEO model.

Future numerical releases should retain this conceptual baseline for comparison and should report:

- number of trajectories;
- all pseudorandom seeds or seed-generation procedure;
- plate-motion/boundary assumptions;
- constraint operators;
- uplift/subsidence and erosion laws;
- invalid/rejected trajectory count;
- ensemble mean topography;
- topographic uncertainty;
- rift/orogen/drainage attractor fields.

### Current visual hypotheses

The conceptual map explores, rather than predicts:

- renewed western North American mountain building/subduction;
- development of interior basin/rift systems;
- possible interior seaways;
- long-term drainage reorganization;
- changing Arctic/Atlantic basin geometry;
- possible Appalachian topographic rejuvenation;
- complex Pacific-margin boundary evolution.

These features are not yet SFE numerical results.

### Validation requirement

Before treating SFE-GEO-100 as a forecasting experiment, the SFE engine should first pass known-answer and shorter-horizon validation tests. Long-horizon results must be compared with established plate-reconstruction/geodynamic methods and accompanied by uncertainty rather than a single deterministic map.

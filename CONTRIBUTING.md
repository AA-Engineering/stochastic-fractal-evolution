# Contributing

Contributions that test, criticize, reproduce, or simplify SFE are welcome.

Particularly useful contributions include:

- literature comparisons identifying prior art;
- mathematical counterexamples;
- baseline implementations;
- reproducibility tests;
- sensitivity analyses;
- alternative constraint operators;
- domain validation;
- demonstrations where SFE fails.

Please distinguish established results from hypotheses and proposed terminology. Reproducible examples should include random seeds and parameter files.
